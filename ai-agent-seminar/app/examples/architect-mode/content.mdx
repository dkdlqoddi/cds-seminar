## 1. 시나리오

이번에는 단순 요약을 넘어, **여러 폴더에 흩어진 raw 데이터** 를 읽어서 보정·시각화·보고서까지 한 번에 만들어야 합니다.

- 입력: `data/raw/2026-W18/` 같은 주차별 폴더 안의 CSV들 (한 주에 100~150개)
- 작업: 캘리브레이션 보정 → 통계 요약 → 채널별 그래프 PNG → 한 페이지 PDF 리포트
- 출력: `reports/2026-W18.pdf`

코드 한 번에 짜기에는 단계가 많습니다. **Code 모드로 곧장 들어가면** 모델이 중간에 길을 잃거나, 폴더 구조를 잘못 가정하고 작성하기 쉽습니다.

## 단계별 처리

1. **load**: 한 주차 폴더의 모든 CSV를 읽어 DataFrame 리스트로 만든다.
   - 컬럼: time, force, displacement (예제 1과 동일하다고 가정)
   - **확인 필요**: 다른 컬럼 구조의 CSV가 섞여 있을 가능성?

2. **calibrate**: 각 DataFrame에서 time < 0.1 구간 force의 평균을 0점으로 빼준다.
   - **확인 필요**: 0점 보정 기준이 force만인가, displacement도 함께인가?

3. **summarize**: 보정된 데이터로 mean/std/max 표 (예제 1과 동일).

4. **plot**: 보정된 force 시계열을 채널 단위로 그래프 PNG로 저장.
   - 50개 이상이면 그래프가 너무 작아짐 → 상위 N개만 표시?
   - **확인 필요**: 한 페이지에 몇 채널까지 보여줄지

5. **report**: matplotlib + reportlab으로 한 페이지 PDF 합치기.

## 주간 실행 인터페이스
\`\`\`
python run_week.py 2026-W18

\`\`\`

- [ ] 0점 보정 기준이 force만인가?
- [ ] 한 페이지에 표시할 채널 수 상한은?

<CodeBlock
  filename="run_week.py"
  lang="python"
  code={`"""주간 측정 리포트 파이프라인 진입점.

사용법: python run_week.py 2026-W18
"""
import sys
from pathlib import Path

from pipeline.load import load_week
from pipeline.calibrate import zero_calibrate
from pipeline.summarize import summarize
from pipeline.plot import plot_top_channels
from pipeline.report import build_pdf


def main(week: str) -> None:
    raw_dir = Path("data/raw") / week
    out_pdf = Path("reports") / f"{week}.pdf"
    out_pdf.parent.mkdir(parents=True, exist_ok=True)

    runs = load_week(raw_dir)
    runs = [zero_calibrate(r, window_s=0.1) for r in runs]
    summary = summarize(runs)
    figure_paths = plot_top_channels(runs, summary, top_n=12)
    build_pdf(out_pdf, week=week, summary=summary, figures=figure_paths)
    print(f"Wrote {out_pdf}")


if __name__ == "__main__":
    main(sys.argv[1])`}

## 왜 Architect → Code 패턴이 중요한가

| Code 모드 단독 | Architect → Code |
| --- | --- |
| 작업 도중 폴더 구조를 잘못 가정 | 시작 전에 사람이 plan을 검토하고 수정 |
| 모델이 길을 잃으면 처음부터 다시 | plan.md가 회복 기준점 역할을 함 |
| 가정이 코드 안에 숨어버림 | 가정이 plan.md에 명시적으로 적힘 |
| 다음 사람이 인수인계 받기 어려움 | plan.md만 봐도 흐름을 이해 |
