## 4. 결과물

<CodeBlock
  filename="summarize.py"
  lang="python"
  code={`"""measurements/ 폴더의 CSV 요약 → summary.csv

각 CSV에서 force 컬럼의 mean/std/max를 계산해
한 개의 요약 표로 합친다.
"""
from pathlib import Path
import pandas as pd

INPUT_DIR = Path("measurements")
OUTPUT = Path("summary.csv")

rows = []
for csv_path in sorted(INPUT_DIR.glob("*.csv")):
    df = pd.read_csv(csv_path)
    rows.append(
        {
            "run_id": csv_path.stem,
            "mean": df["force"].mean(),
            "std": df["force"].std(),
            "max": df["force"].max(),
        }
    )

summary = pd.DataFrame(rows)
summary.to_csv(OUTPUT, index=False)

print(summary.head())
print(f"\\nWrote {len(summary)} rows to {OUTPUT}")`}
/>

## 5. 검증 방법

<Callout kind="check" title="이 결과를 신뢰해도 될까? — 3가지만 직접 확인">
1. **행 개수**: `summary.csv`의 행 수가 50인지 본다 (Excel로 열어 마지막 행 번호 확인).
2. **샘플 1개 수동 비교**: `run_001.csv`를 Excel로 열어 force 평균을 직접 계산한 값과 표 1행의 mean이 일치하는지 본다.
3. **이상치 한눈에 보기**: max 컬럼을 정렬해서 비정상적으로 큰 값이 있는지 확인.

**셋 다 통과하면** 이 스크립트는 다음 주에도 그대로 돌릴 수 있습니다.
</Callout>

<Callout kind="warn" title="흔한 함정">
- 어떤 CSV는 `force`가 아니라 `Force`(대문자)일 수 있다 → Roo에게 "컬럼 이름을 대소문자 무시하고 매칭해줘"라고 추가 지시.
- 빈 CSV가 섞여있을 수 있다 → 스크립트에 `if df.empty: continue` 한 줄 추가 요청.
- 단위가 다른 파일(N vs kN)이 섞여있을 수 있다 → 이건 Roo도 모릅니다. 사람이 정의해줘야 합니다.
</Callout>
