## 시나리오

매일 야간 측정이 끝나면 `D:\measurements\YYYY-MM-DD\` 폴더 안에 50개 안팎의 CSV가 떨어집니다.
지금까지는 본인이 출근해서 한 시간 동안 Excel로 모아 평균과 표준편차를 계산해 보고서를 만들고 있었다고 칩시다.

이걸 n8n 워크플로우 하나로 옮기면, **출근 전 6시에 자동으로 끝나 있고** Excel 보고서는 정해진 폴더에 저장돼 있습니다.

## 노드별 설정값

### 1. Schedule Trigger

| 필드 | 값 |
| --- | --- |
| Trigger Interval | `Days` |
| Hour | `6` |
| Minute | `0` |

### 2. Set — 어제 날짜 폴더 경로 계산

n8n의 **Expression** 으로 어제 날짜를 그대로 식으로 넣습니다.

| 필드 | 값 |
| --- | --- |
| Mode | `Manual Mapping` |
| Field Name | `folder` |
| Field Value | `={{ "D:\\measurements\\" + $now.minus({days: 1}).toFormat("yyyy-MM-dd") }}` |
| Field Name | `reportPath` |
| Field Value | `={{ "D:\\measurements\\report\\" + $now.minus({days: 1}).toFormat("yyyy-MM-dd") + ".xlsx" }}` |

<Callout kind="tip" title="Expression 문법 한 줄 요약">
`{{ ... }}` 안에 들어가면 JS 식입니다. `$now` 는 luxon DateTime 객체. `$json` 은 입력 데이터.
앞 노드 결과는 `$node["노드이름"].json` 으로 접근합니다.
</Callout>

### 3. Code — 폴더 안 CSV 목록화

```javascript
const fs = require("fs");
const path = require("path");

const folder = $input.first().json.folder;
const files = fs.readdirSync(folder)
  .filter(f => f.toLowerCase().endsWith(".csv"))
  .map(f => ({ json: { fullPath: path.join(folder, f), name: f } }));

return files;
```

### 4. Read Binary File

| 필드 | 값 |
| --- | --- |
| File Selector | `={{ $json.fullPath }}` |
| Property Name | `data` |

### 5. Code — CSV 파싱 + 통계

```javascript
const rows = [];
for (const item of items) {
  const text = item.binary.data
    ? Buffer.from(item.binary.data.data, "base64").toString("utf8")
    : "";
  const lines = text.split(/\r?\n/).filter(Boolean);
  const header = lines[0].split(",");
  const numericCols = header.map((_, i) => i).filter(i => i > 0);

  // 각 숫자 컬럼의 평균/표준편차
  const stats = {};
  for (const ci of numericCols) {
    const vals = lines.slice(1)
      .map(l => parseFloat(l.split(",")[ci]))
      .filter(v => !isNaN(v));
    const mean = vals.reduce((a, b) => a + b, 0) / vals.length;
    const std = Math.sqrt(
      vals.reduce((s, v) => s + (v - mean) ** 2, 0) / vals.length
    );
    stats[`${header[ci]}_mean`] = Number(mean.toFixed(4));
    stats[`${header[ci]}_std`] = Number(std.toFixed(4));
  }

  rows.push({ json: { file: item.json.name, ...stats } });
}
return rows;
```
