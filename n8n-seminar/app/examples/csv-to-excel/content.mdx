## 시나리오

매일 야간 측정이 끝나면 `D:\measurements\YYYY-MM-DD\` 폴더 안에 50개 안팎의 CSV가 떨어집니다.
지금까지는 본인이 출근해서 한 시간 동안 Excel로 모아 평균과 표준편차를 계산해 보고서를 만들고 있었다고 칩시다.

이걸 n8n 워크플로우 하나로 옮기면, **출근 전 6시에 자동으로 끝나 있고** Excel 보고서는 정해진 폴더에 저장돼 있습니다.

## 노드별 설정값

### 0. 경로 및 파일 생성

```
# 경로 생성
D:\\measurements\\
D:\\measurements\\report\\  --> 결과 저장하는 Directory
D:\\measurements\\ + {날짜} --> Data가 들어있는 Directory

# 파일 생성
D:\\measurements\\ {날짜} \\example.csv --> 처리할 csv 파일
```

example.csv 파일 내용

```csv
Name,Score,Age
Alice,85,20
Bob,92,25
Charlie,78,22
David,88,24
Eve,95,21
```

### 1. Schedule Trigger

| 필드 | 값 |
| --- | --- |
| Trigger Interval | `Minutes` |
| Minutes Between Triggers | `5` |

### 2. Edit Fields — 어제 날짜 폴더 경로 계산

n8n의 **Expression** 으로 어제 날짜를 그대로 식으로 넣습니다.

| 필드 | 값 |
| --- | --- |
| Mode | `Manual Mapping` |
| Field Name | `folder` |
| Field Type | `String` |
| Field Value | `={{ "D:\\measurements\\" + $now.minus({days: 1}).toFormat("yyyy-MM-dd") }}` |
| --- | --- |
| Field Name | `reportPath` |
| Field Type | `String` |
| Field Value | `={{ "D:\\measurements\\report\\" + $now.minus({days: 1}).toFormat("yyyy-MM-dd") + ".xlsx" }}` |

<Callout kind="tip" title="Expression 문법 한 줄 요약">
`{{ ... }}` 안에 들어가면 JS 식입니다. `$now` 는 luxon DateTime 객체. `$json` 은 입력 데이터.
앞 노드 결과는 `$node["노드이름"].json` 으로 접근합니다.
</Callout>

### 3. Code in JavaScript — 폴더 안 CSV 목록화

```javascript
const fs = require("fs");
const path = require("path");

const folder = $input.first().json.folder;
const files = fs.readdirSync(folder)
  .filter(f => f.toLowerCase().endsWith(".csv"))
  .map(f => ({ json: { fullPath: path.join(folder, f), name: f } }));

return files;
```

| 필드 | 값 |

| Property Name | `data` |

### 5. Code in JavaScript — CSV 파싱 + 통계

```javascript
const results = [];
const items = $input.all();

for (let i = 0; i < items.length; i++) {
  // 1. 'data'라는 이름의 바이너리 데이터를 안전하게 버퍼 형태로 가져옵니다.
  // (n8n 내장 함수를 사용하여 메모리/디스크 저장 방식에 상관없이 정확히 읽어옵니다)
  const buffer = await this.helpers.getBinaryDataBuffer(i, 'data');
  
  // 2. 버퍼 데이터를 사람이 읽을 수 있는 텍스트(UTF-8)로 변환
  const csvContent = buffer.toString('utf8');
  
  // 3. 줄바꿈(\n 또는 \r\n)을 기준으로 각 행을 분리
  const lines = csvContent.trim().split(/\r?\n/);
  
  // 4. 첫 번째 줄에서 헤더(Name, Score, Age) 추출
  const headers = lines[0].split(',');
  
  // 5. 두 번째 줄부터 끝까지 실제 데이터 파싱
  for (let j = 1; j < lines.length; j++) {
    const values = lines[j].split(',');
    const row = {};
    
    headers.forEach((header, index) => {
      let value = values[index].trim();
      
      // Score와 Age는 계산하기 편하도록 숫자(Number) 타입으로 변환
      if (header === 'Score' || header === 'Age') {
        value = Number(value);
      }
      
      row[header] = value;
    });

    // 6. JSON 결과 배열에 추가
    results.push({ json: row });
  }
}

return results;
```
