## 시나리오

야간 측정 결과가 새벽에 `D:\measurements\incoming\` 폴더에 자동으로 떨어집니다.
출근 전까지 측정이 잘 끝났는지 확인하려고 매일 새벽에 PC를 켜는 일은 더 이상 하고 싶지 않습니다.

n8n의 **Local File Trigger** 가 폴더 변경을 감시해, 새 파일이 들어오자마자
Teams 채널로 "신규 측정 파일: `xxx.csv` (12.4 MB)" 한 줄을 자동 전송하게 만들 수 있습니다.

## 노드별 설정값

### 1. Local File Trigger

| 필드 | 값 |
| --- | --- |
| Trigger On | `Changes Involving a Specific Folder` |
| Folder to Watch | `D:\measurements\incoming` |
| Watch for | `File Added` |
| File Extensions | `csv` |

<Callout kind="info" title="n8n이 파일을 어떻게 감시하나">
내부적으로 [chokidar](https://github.com/paulmillr/chokidar)를 씁니다. 폴링이 아닌 OS의 파일 시스템 이벤트 기반이라
새 파일이 떨어지면 거의 즉시 트리거됩니다. 단, 네트워크 드라이브(`\\server\share\`)는 폴링으로 떨어지므로
지연이 5~10초 있을 수 있습니다.
</Callout>

### 2. IF — 0바이트 파일 거르기

가끔 측정 장비가 파일을 만들고 데이터를 다 쓰기 전에 트리거가 발화하는 경우가 있습니다.
**0바이트면 알림을 보내지 않도록** 합니다.

| 조건 | 설정 |
| --- | --- |
| Value 1 | `={{ $json.event === "add" ? $json.size : 0 }}` |
| Operation | `Larger` |
| Value 2 | `0` |

### 3. Set — 메시지 텍스트 조립

| 필드 | 값 |
| --- | --- |
| Field Name | `text` |
| Field Value | `={{ "📊 신규 측정 파일: " + $json.path + " (" + ($json.size / 1024 / 1024).toFixed(1) + " MB)" }}` |

### 4. HTTP Request — Teams Incoming Webhook

Teams 채널 → ⋯ → **Connectors** → **Incoming Webhook** 에서 발급받은 URL을 씁니다.
이 URL은 외부 인증 없이 동작하므로 n8n Credential에 보관해 노출을 막습니다.

| 필드 | 값 |
| --- | --- |
| Method | `POST` |
| URL | `(Teams에서 발급받은 webhook URL)` |
| Body Content Type | `JSON` |
| JSON Body | `{ "text": "{{ $json.text }}" }` |

Slack을 쓴다면 같은 형태에 URL과 페이로드만 다음처럼 바꿉니다:

```json
{ "text": "📊 신규 측정 파일: ..." }
```

## Import 가능한 JSON

```json
{
  "name": "예제2 · 측정 폴더 → Teams 알림",
  "nodes": [
    {
      "parameters": {
        "triggerOn": "folder",
        "path": "D:\\measurements\\incoming",
        "events": ["add"],
        "options": { "ignored": "**/*.tmp" }
      },
      "type": "n8n-nodes-base.localFileTrigger",
      "name": "Local File Trigger",
      "position": [0, 0]
    },
    {
      "parameters": {
        "conditions": {
          "options": { "caseSensitive": true, "typeValidation": "strict" },
          "conditions": [
            {
              "operator": { "type": "number", "operation": "gt" },
              "leftValue": "={{ $json.size }}",
              "rightValue": 0
            }
          ],
          "combinator": "and"
        }
      },
      "type": "n8n-nodes-base.if",
      "name": "IF size > 0",
      "position": [240, 0]
    },
    {
      "parameters": {
        "assignments": {
          "assignments": [
            {
              "name": "text",
              "type": "string",
              "value": "={{ '📊 신규 측정 파일: ' + $json.path + ' (' + ($json.size / 1024 / 1024).toFixed(1) + ' MB)' }}"
            }
          ]
        }
      },
      "type": "n8n-nodes-base.set",
      "name": "Compose message",
      "position": [480, 0]
    },
    {
      "parameters": {
        "method": "POST",
        "url": "https://your-tenant.webhook.office.com/webhookb2/...",
        "sendBody": true,
        "specifyBody": "json",
        "jsonBody": "={ \"text\": \"{{ $json.text }}\" }"
      },
      "type": "n8n-nodes-base.httpRequest",
      "name": "Teams Webhook",
      "position": [720, 0]
    }
  ],
  "connections": {
    "Local File Trigger": { "main": [[{ "node": "IF size > 0", "type": "main", "index": 0 }]] },
    "IF size > 0": { "main": [[{ "node": "Compose message", "type": "main", "index": 0 }], []] },
    "Compose message": { "main": [[{ "node": "Teams Webhook", "type": "main", "index": 0 }]] }
  }
}
```

<Callout kind="warn" title="Webhook URL은 비밀번호와 같습니다">
이 URL이 노출되면 누구나 채널에 메시지를 보낼 수 있습니다. n8n 워크플로우 export 시
URL을 직접 박지 말고 **Credential** 로 빼서 export 시 마스킹되도록 하세요. (n8n은 자격증명을 export에 포함하지 않습니다.)
</Callout>
