## 본질적 차이: "GUI에서 만든다"는 것의 의미

Python 스크립트도 n8n 워크플로우도 같은 일을 할 수 있습니다. 그런데 n8n은 그것을
**그림(GUI)** 으로 만듭니다. 단순히 "코딩 안 해도 된다"가 다가 아닙니다.

| 관점 | Python/매크로 스크립트 | n8n 워크플로우 |
| --- | --- | --- |
| 만드는 사람 | 본인 (코드 짜는 사람) | 본인 + 팀원 (그림 보고 이해 가능) |
| 실행 | 본인 PC, 손으로 / 작업 스케줄러 | n8n 서버, 24시간 자동 |
| 모니터링 | `print()` 와 로그 파일 | 실행 1건마다 노드별 입출력 그대로 보존 |
| 재시도 | 본인이 짜야 함 | 노드 옵션으로 N회 재시도 + 백오프 |
| 에러 알림 | 본인이 짜야 함 | Error Trigger 워크플로우 한 번 만들면 끝 |
| 변경 이력 | git이 있으면 그나마, 매크로는 사실상 없음 | 워크플로우 자체가 JSON으로 export 가능 → git에 올리기 쉬움 |
| 인수인계 | "이 스크립트 어디 있죠?" → "C:\\users\\…" | URL 하나 / Workflow 이름 하나 |

## "왜 GUI인가" — 인수인계의 비대칭

엔지니어가 회사를 옮기거나 다른 프로젝트로 떠날 때, **남은 사람이 가장 먼저 만나는 자산은 코드가 아니라 그림** 입니다.

<Callout kind="info" title="현장에서 자주 보는 패턴">
선임이 만들어 둔 Python 스크립트는 보통 이렇게 끝납니다:
"이거 실행하면 결과 나오니까 그냥 매일 돌리세요. 막히면 저한테 문의."

선임 퇴사 후 이 스크립트는 거의 100% **블랙박스** 가 됩니다. 어디서 무슨 데이터를
읽는지, 어디로 결과를 쓰는지 — 코드를 한 줄씩 읽지 않으면 알 수 없습니다.

n8n 워크플로우는 같은 작업을 **노드 8개의 그림** 으로 보여줍니다.
"아, 이 첫 노드가 측정 폴더에서 CSV 읽고, 다음이 평균 계산하고, 마지막이 메일 보내는구나" —
**열어보는 5초 안에 흐름이 잡힙니다.**
</Callout>

## 안전망: Code 노드로 언제든 코드를 끼워넣을 수 있다

n8n이 "노드 만들 줄만 알면 만능" 같은 환상을 부추기지는 않습니다.
**복잡한 로직은 Code 노드** 안에 JavaScript(또는 Python)로 그대로 넣을 수 있습니다.

```javascript
// Code 노드 안에 그대로 들어가는 JS 예시
// 들어온 측정값들을 표준편차로 정규화
const values = items.map(i => i.json.measurement);
const mean = values.reduce((a, b) => a + b, 0) / values.length;
const std = Math.sqrt(values.reduce((s, v) => s + (v - mean) ** 2, 0) / values.length);

return items.map(i => ({
  json: {
    ...i.json,
    z_score: (i.json.measurement - mean) / std,
  },
}));
```

따라서 "쉬운 부분은 노드로, 어려운 부분만 Code로" 라는 하이브리드가 가능합니다.

## 언제 n8n이 어울리지 않나

솔직하게:

- **저지연 실시간 처리** — 1 kHz 이상 샘플링으로 들어오는 신호 처리는 어울리지 않습니다.
- **무거운 수치 연산** — 큰 행렬 곱·이미지 변환·DL 추론은 NumPy/PyTorch에 맡기세요.
  단, n8n에서 **그 작업을 트리거** 하고 결과를 받아오는 것은 잘 맞습니다.
- **본인 혼자 한 번만 쓸 일회성 작업** — 즉석 셸 스크립트가 더 빠릅니다.

## 의사결정 표

| 상황 | 권장 |
| --- | --- |
| 매일/매시간 자동 반복, 결과를 다른 팀과 공유 | **n8n** |
| 한 번만 돌리고 끝, 결과를 본인 PC에서만 봄 | Python 스크립트 |
| 100ms 내 응답이 필요한 장비 제어 | LabVIEW / 임베디드 코드 |
| 무거운 계산 자체 | Python (n8n이 호출만) |
| 인수인계가 곧 일어날 예정 | **n8n** (그림 한 장이 매뉴얼 50줄을 이김) |
