## 시나리오

지금까지는 손으로 `python ...` 을 입력해 flow 를 돌렸습니다. 진짜 운영에서는 다음이 필요합니다.

- **자동 실행** — 매시 정각, 매일 새벽 등 정해진 시간에 알아서 돌아야 한다.
- **UI에서 관리** — 어느 deployment 가 언제 실패했는지 클릭으로 확인.
- **파라미터로 입력 분리** — A 라인용 / B 라인용 같은 입력 차이만으로 코드를 복사하지 않는다.

이 셋을 만족시키는 단위가 **Deployment** 입니다.

## 사전 준비

3강을 완료해 사내 Prefect 서버에 프로파일이 붙어 있어야 합니다.

```bash
prefect profile use cds-internal
prefect config view
# PREFECT_API_URL='http://12.81.225.154:10000/api'
```

## 코드

가장 단순한 등록 방법은 `flow.serve()` 입니다. 이 한 호출이 (1) deployment 등록과 (2) worker 역할까지 같이 합니다.
**학습/소규모 환경** 에 가장 잘 맞습니다.

<CodeBlock
  filename="flows/04_deployment.py"
  lang="python"
  code={`from pathlib import Path
import importlib.util

# 03 예제의 flow 를 그대로 재사용
HERE = Path(__file__).resolve().parent
spec = importlib.util.spec_from_file_location("ex03", HERE / "03_report_to_postgres.py")
ex03 = importlib.util.module_from_spec(spec); spec.loader.exec_module(ex03)
process_report = ex03.process_report

DEFAULT_REPORT = str(HERE / "sample_reports" / "LOT_A001_2026-05-07_08-01.json")


def main() -> None:
    process_report.serve(
        name="hourly-A-line",
        cron="0 * * * *",                                # 매시 정각
        parameters={"report_path": DEFAULT_REPORT},      # 라인별 입력
        tags=["seminar", "report-pipeline"],
        description="A 라인 보고서를 매시 정각에 처리해 outfeed + Postgres 적재.",
    )


if __name__ == "__main__":
    main()`}
/>

## 실행

```bash
PREFECT_API_URL="http://12.81.225.154:10000/api" python flows/04_deployment.py
```

실행하면 콘솔이 다음과 같이 멈춥니다 (worker 가 도는 중).

```text
Your flow 'report-to-postgres' is being served and polling for scheduled runs!
```

이 상태에서 브라우저로 `http://12.81.225.154:10000` 을 열면:

- **Deployments** 탭에 `report-to-postgres / hourly-A-line` 이 등록돼 있습니다.
- **Schedules** 에 `0 * * * *` 가 보입니다.
- 매시 정각이 되면 자동으로 Run 이 생기고, 즉시 시험하고 싶다면 **"Run"** 버튼으로 즉시 실행할 수도 있습니다.

<Callout kind="warn" title="이 프로세스를 닫으면 worker 도 죽는다">
`flow.serve()` 는 학습용 가장 단순한 운용입니다. 실제 운영에서는 worker 를 별도 서비스로 띄워두어야 안정적입니다.

```bash
prefect work-pool create default-pool --type process
prefect deploy flows/04_deployment.py:process_report \\
  -n hourly-A-line --pool default-pool --cron "0 * * * *" \\
  --param report_path=$DEFAULT_REPORT
prefect worker start --pool default-pool   # PC 부팅 시 자동 실행되도록 등록 권장
```

이렇게 해두면 사용자가 노트북을 닫아도 사내 PC 의 worker 프로세스가 일을 계속 가져갑니다.
</Callout>

## cron 외의 스케줄 종류

| 종류 | 코드 | 언제 어울리나 |
| --- | --- | --- |
| `cron="0 * * * *"` | 분 시 일 월 요일 | 매시간/매일 새벽처럼 시각이 정해진 작업 |
| `interval=60` (초) | 일정 주기마다 | "30초마다 폴더 확인" 같은 짧은 주기 |
| `rrule="..."` | iCalendar 표준 | 평일만 / 매월 마지막 영업일 등 복잡한 규칙 |

세 가지를 섞을 수도 있습니다.

## 같은 flow를 라인별로 두 deployment로

같은 코드를 입력만 바꿔 두 번 등록하면, UI 에서 **두 개의 독립된 deployment** 처럼 관리됩니다.

```python
process_report.serve(
    name="hourly-A-line",
    cron="0 * * * *",
    parameters={"report_path": "/share/A-line/latest.json"},
    tags=["A-line"],
)

# (다른 스크립트에서)
process_report.serve(
    name="daily-B-line",
    cron="30 6 * * *",
    parameters={"report_path": "/share/B-line/latest.json"},
    tags=["B-line"],
)
```
