## 시나리오

리스트를 받아 각 원소를 제곱한 뒤 합계를 구하는 간단한 함수입니다.
Prefect 데코레이터 두 개만 추가하면 자동 로깅과 task 단위 추적이 따라옵니다.

<FlowDiagram
  caption="@task 두 개를 묶는 @flow 한 개. 평범한 함수 호출과 똑같이 돌릴 수 있다."
  steps={[
    { type: "input", name: "numbers (list)", detail: "[1, 2, 3, 4, 5]" },
    { type: "task", name: "@task square(n)", detail: "각 원소 제곱" },
    { type: "task", name: "@task total(values)", detail: "합 계산" },
    { type: "output", name: "return", detail: "= 55" },
  ]}
/>

## 코드

<CodeBlock
  filename="flows/01_hello_flow.py"
  lang="python"
  code={`from prefect import flow, task, get_run_logger


@task
def square(n: int) -> int:
    logger = get_run_logger()
    logger.info("squaring %d", n)
    return n * n


@task
def total(values: list[int]) -> int:
    return sum(values)


@flow(name="hello-flow", log_prints=True)
def hello_flow(numbers: list[int]) -> int:
    """list of ints -> sum of squares."""
    print(f"start: numbers = {numbers}")
    squared = [square(n) for n in numbers]
    s = total(squared)
    print(f"sum of squares = {s}")
    return s


if __name__ == "__main__":
    result = hello_flow([1, 2, 3, 4, 5])
    assert result == 55, result
    print("OK", result)`}
/>

## 실행

```bash
python flows/01_hello_flow.py
```

처음 한 번은 임시 로컬 서버가 떠서 약간 느리지만, 한 번 떠 있으면 다음 실행은 즉시 시작합니다.

## 무엇이 일어났는가

콘솔 로그가 다음과 같이 나옵니다 (시간만 지웠습니다).

```text
INFO    | prefect - Starting temporary server on http://127.0.0.1:8652
INFO    | Flow run 'judicious-squirrel' - Beginning flow run for flow 'hello-flow'
INFO    | Flow run 'judicious-squirrel' - start: numbers = [1, 2, 3, 4, 5]
INFO    | Task run 'square-8be' - squaring 1
INFO    | Task run 'square-8be' - Finished in state Completed()
INFO    | Task run 'square-720' - squaring 2
...
INFO    | Task run 'total-d28' - Finished in state Completed()
INFO    | Flow run 'judicious-squirrel' - sum of squares = 55
INFO    | Flow run 'judicious-squirrel' - Finished in state Completed()
OK 55
```

세 가지를 짚어두면 됩니다.

1. **`@task` 한 번 호출 = Task Run 한 개.** 같은 함수 `square` 가 5번 호출됐으니 Task Run 도 5개.
2. **`flow run` 에는 사람이 알아보기 좋은 이름**(`judicious-squirrel`) 이 자동 생성되어 UI 에서 검색이 쉽습니다.
3. `log_prints=True` 덕에 `print()` 가 그대로 Prefect 로그에 잡힙니다 — 따로 `logger.info()` 를 안 써도 됩니다.

<Callout kind="tip" title="이 예제의 핵심 한 줄">
`@flow` 와 `@task` 는 **함수 동작을 바꾸지 않습니다.** 그냥 옆에서 실행을 지켜보고 기록할 뿐입니다.
즉, Prefect 도입은 기존 코드를 거의 바꾸지 않고도 가능합니다.
</Callout>
